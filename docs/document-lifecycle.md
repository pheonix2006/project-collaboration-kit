# 文档生命周期

本页定义材料何时能指导判断、何时能被执行、何时只可追溯。信息类别及其主要权威位置
见[信息权威来源](source-of-truth.md)；生命周期不是又一份职责映射，也不规定固定目录。

## 六种语义

| 语义 | 定义 | 使用约束 |
| --- | --- | --- |
| 草拟 | 正在形成、尚未确认的材料或候选结论。 | 可以用于讨论和审阅，不能作为当前判断依据或执行授权。 |
| 当前有效 | 已确认且仍可指导当前判断的材料。 | 必须能从当前入口或索引找到；一旦失效、完成或被替代，应更新其状态。 |
| 当前可执行 | 在当前有效基础上，范围、责任和验收已获确认，允许开始执行的材料。 | 通常是计划或明确任务；不能由草拟、历史 TODO 或旧聊天记录推断获得。 |
| 已完成 | 已达到约定终点并保留结果、验证和缺口的材料。 | 不再作为待办；若有后续工作，应创建新的当前计划或当前状态项。 |
| 已替代 | 曾经有效但已由更高版本或新决定取代的材料。 | 必须指向新的权威内容，避免读者将其误作现行结论。 |
| 历史材料 | 为追溯保留的旧记录、原始日志或旧口径报告。 | 只用于了解来由或核对证据；不能自动恢复为当前判断或执行指令。 |

## 各类材料如何流转

| 材料 | 常见流转 | 退出当前入口时的处理 |
| --- | --- | --- |
| 当前设计 | 草拟 → 当前有效 → 已替代或历史材料 | 新设计成为当前有效入口；旧设计显式链接到替代者并保留取舍背景。 |
| 当前计划 | 草拟 → 当前可执行 → 已完成、已替代或历史材料 | 完成或取消后从当前计划入口移出；验收证据进入对应历史证据。 |
| 当前状态 | 草拟 → 当前有效 → 已完成或历史材料 | 项目级只维护一个当前入口；上一轮状态作为快照归档或被简要吸收到历史证据。 |
| 报告 | 草拟 → 当前有效 → 已完成或历史材料 | 当前报告只保留现行口径；里程碑结束后保留结论、证据与缺口，旧口径转为历史材料。 |
| 日志 | 草拟或持续追加 → 历史材料；必要部分提炼为已完成的历史证据 | 原始日志不改写成当前指令；稳定规律另行沉淀为可复用经验，并链接原始证据。 |

“已完成”描述工作或报告在其约定范围内结束；“历史材料”描述其阅读用途。一个已完成
计划和其证据通常也会成为历史材料，但两者不能再因为旧 TODO 存在而恢复为当前可执行。
需要继续推进时，必须重新确认范围和验收，并建立新的当前状态或当前计划。

## 归档与状态表达

归档不是删除。归档应保留可追溯的内容、时间或版本背景、证据链接，以及在适用时指向
替代材料的链接；它只是把材料从默认读取路径移出。历史 TODO 同样保留历史价值，但不能
自动恢复为待办或授权。

项目可按自身规模选择下列一种或组合表达方式：

- 目录位置：将当前入口与 `archive`、`history` 等追溯区域分开。
- 索引：在目录页或项目入口标注唯一当前入口，并列出已完成、已替代和历史材料的链接。
- 显式元数据：用标题、状态字段、日期或替代链接标记草拟、当前有效、当前可执行等状态。

无论采用哪种方式，读者应尽量无需打开正文就能判断材料是否仍有效；这些只是可选的
表达载体，不构成下游项目必须复制的目录结构。
