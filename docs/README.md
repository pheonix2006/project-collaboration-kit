# 文档导航

这里是仓库文档的路由入口。先阅读仓库根目录的 `AGENTS.md` 和 `README.md`，再按任务读取下列位置；当前项目概况与唯一当前状态分别记录在 `project-overview.md` 和 `current-development-status.md`。

| 位置 | 职责与状态 |
| --- | --- |
| [specs/](specs/README.md) | 当前有效设计与其归档 |
| [plans/](plans/README.md) | 已确认、当前可执行的计划与其归档 |
| [dev-log/](dev-log/README.md) | 按月份保存的实施与验证证据 |
| [pitfalls/](pitfalls/README.md) | 可跨任务复用的故障规律 |
| [decisions/](decisions/README.md) | 重大既成决定及其理由 |
| [reports/](reports/README.md) | 当前权威报告与其归档 |

目录名本身表达生命周期状态：`active`、`current` 中的材料可作为当前依据；`archive` 只保留历史证据，不能自动恢复为当前指令。没有实际内容时保留空目录，不为了齐全制造文档。

维护时把事实写到其唯一权威位置；其他文档只保留必要摘要并链接回该位置。稳定规则放在 `AGENTS.md`，单次执行细节放在相应的计划、日志或报告中。
